# Ngôi Nhà Số Enterprise — Tuấn Phạm

Ứng dụng quản trị đa năng tích hợp bộ 33 công cụ điều hành công việc, đời sống và đội ngũ nhân sự AI.

## Công Nghệ Sử Dụng
- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Shadcn UI Glassmorphism Dark Enterprise Theme
- **Data Persistence**: Offline-First LocalForage (IndexedDB / LocalStorage)
- **Interactive Tools**: 33 công cụ chuyên biệt nhúng tương tác trực tiếp
- **Deployment**: Tối ưu sẵn sàng deploy lên Vercel / Netlify / GitHub Pages

## Chạy Ứng Dụng Tại Local
```bash
npm install
npm run dev
```

## Build Production
```bash
npm run build
```
